## 工作空间 API

新版 `sk-ws-` Key 需要在第 1 步填写工作空间 Base URL：`https://<WorkspaceID>.cn-beijing.maas.aliyuncs.com`。第 3 步使用同一工作空间时，LLM URL 为 `https://<WorkspaceID>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；验证会实际调用所选模型。
